Overview

KINKORN is a meal pre-ordering project explored pain points in university canteen ordering and designed a meal pre-ordering experience around user needs.

Responsibilities

  • Conducted user research and interviews to identify pain points in the current ordering process.
  • Defined user personas and key needs to inform product design.
  • Created user flows, wireframes, and UI designs for web and mobile platforms.
  • Developed the frontend of the application using HTML, Django and Flutter.
